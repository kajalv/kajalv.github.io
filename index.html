Research

  1. ISPA 2018 · IEEE

    Predicting Execution Time of CUDA Kernel Using Static Analysis ↗

    Gargi Alavani, Kajal Varma, Santonu Sarkar

    An analytical model that predicts a GPU kernel’s execution time from its intermediate PTX code without running it, so developers can fix inefficient code before running it.

  2. VLSID 2017 · IEEE

    DTLB: Deterministic TLB for Tightly Bound Hard Real-time Systems ↗

    Kajal Varma, Geeta Patil, Biju Raveendran

    A TLB architecture that saves a task’s TLB contents to its PCB on preemption and restores them on resume. It reduces misses and per-access time, with 6.74% average dynamic energy savings over a conventional TLB in MemSim.
